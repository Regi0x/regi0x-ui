# UI pattern workflow

Use stable canonical components first. A pattern describes interaction among components, state transitions, permissions/error/loading behavior, keyboard flow, mobile/narrow behavior and EN/RU content. Do not duplicate component markup inside the pattern. Add a live example and document the pattern's preconditions and failure states.
